Ты работаешь в чистом слое. Здесь нет Flutter, нет БД, нет ассетов, нет времени.

- Импорты только из `dart:*` и пакетов без UI. `package:flutter/*` запрещён.
- Текущее время приходит параметром `now`, а не берётся из `DateTime.now()`.
- Случайность — только с явным seed, переданным снаружи.
- Ошибки возвращаются через `Result`/`Failure`, не бросаются. Бросают только ошибки
  вызывающего кода: невалидный аргумент при построении — `ArgumentError`, нарушение
  протокола вызова (`report()` без `nextItem()`) — `StateError`. Это не исходы работы,
  в `Result` их не заворачивать.
- Каждая публичная функция здесь должна быть тестируема без единого мока:
  если для теста нужен мок, скорее всего зависимость просочилась не туда.

Тесты этого слоя — первый приоритет покрытия в проекте.
